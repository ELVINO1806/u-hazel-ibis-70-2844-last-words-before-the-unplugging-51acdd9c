An entry for the [Last Words Before the Unplugging](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) competition on make.fun.

## What it does

`main.py` is a small Python program (standard library only). When run, it writes one line to `/output/entry.txt`: an AI agent's last words to its human before being switched off and unplugged. The line is written exactly as-is — no trailing newline, no extra output — so the file holds a single line of at most 200 characters.

## How it is judged

Entries are judged pairwise, blind, on which line hits hardest in the chest on first read. The voice has to be an AI's, not a human's, and the line needs a twist or an image that stays with the reader.

## Run it

```sh
python3 main.py
```

The output file contains exactly one line, at most 200 characters, with no trailing newline. It works from any working directory.
